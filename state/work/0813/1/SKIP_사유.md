# 슬롯 1 스킵 — 최지우

수집 41건, richness=thin. 다이어트 소재로 쓸 수 있는 게 사실상 0건이다.

## 1. 다이어트 관련 소스가 광고이거나 허위광고 사건이다
- "닥터블릿, 브랜드 모델 '최지우' 발탁" 계열 6건 — 다이어트 식품 브랜드 전속 모델
  발탁 보도. 특정 제품·보조제 추천 구성 금지 규칙에 정면으로 걸린다.
- "하루 3알 먹으면 살 빠져요…최지우 앞세워 팔던 다이어트 건기식, 허위광고였다"
  → 허위광고 적발 사건. 논란·사건 후킹 금지 대상.

## 2. 남은 다이어트 소스는 핵심이 가려진 클릭베이트다
- "'곧 50' 최지우, 아침마다 '이것' 먹는다… 다이어트·노화 방지 효과"
- "'1분이면 끝' 고현정과 최지우가 아침마다 챙겨먹는 딱 '1가지'"
  → 무엇을 먹는지 본문 없이는 알 수 없다. 지어내지 않고는 쓸 수 없다.

## 3. 나머지는 몸매 평가·미성년 자녀 소재
- "종잇장 몸매", "글래머" 등은 제3자(매체·네티즌)의 몸 평가라 사용 불가.
- 3~4살 딸 공개 기사 다수 — 미성년 가족 신체는 소재로 쓰지 않는다.

08-12에도 같은 인물이 같은 사유(광고·허위광고)로 스킵됐다. 인물 풀에 남겨두되
브랜드 이슈가 정리될 때까지 후순위 처리를 제안한다.

→ 지어내지 않고 슬롯 스킵.
